# 真实任务采集与回放

填写 `真实测试数据采集模板.xlsx`，另存为 `filled/真实测试.xlsx`。不要直接在空白模板中长期保存个人数据；`filled/` 和 `converted*/` 已加入忽略规则。无需安装新的Python包。

## 收集流程

1. 取得参与者同意，仅记录匿名编号和脱敏任务标题。不要收集聊天原文、密码、姓名、学号。
2. 为每人预先确定连续观察期（建议7–14天），起止时间按30分钟对齐、统一北京时间。每名用户一次观察对应一个观察编号。不同用户编号不要复用；同一用户不同观察期不要重叠。
3. 观察期开始时记录已知课表和所有固定不可用时间，一次安排一行。重复课程要逐日展开。动态新增固定事件当前回放不支持，不能伪装成开始时已知。
4. 只纳入在观察期内发布的新任务。发布时填写预计耗时、类别、难度、优先级和截止时间。后续不根据实际结果改写这些初始字段。观察开始前已做过的积压任务暂不支持。
5. 逐次记录实际工作时段，暂停后另起一行；有效分钟不含休息。任务表填写真实有效工作总分钟（可手动累加完整执行记录）。实际完成时间是整项任务结束时间。
6. 观察结束时更新所有任务状态；未完成、取消、未开始的任务也保留。空值代表未知，不用0或预计值代替实际耗时。执行记录表可空，任务总耗时已知即可做受限回放。

## 格式

Excel第一行是固定中文表头，不增删/改名。时间可填写Excel日期时间，或 `2026-10-18 09:00`。数字不要带“分钟”等单位。下拉框只用于帮助填写，转换时会再次验证。填表区域预设200行，可继续向下增加。

模板没有真实或虚构参与者数据。表内“字段说明”提供示例值，仅供参考，转换器不读取它。

## 转换（在 model 目录下）

先只导出观测数据，任何完成状态都保留：

```bash
python scripts/convert_real_dataset.py \
  --input real_data/filled/真实测试.xlsx \
  --output real_data/converted-observations \
  --observations-only
```

全部任务都已完成且有效耗时已知时，转换成回放格式：

```bash
python scripts/convert_real_dataset.py \
  --input real_data/filled/真实测试.xlsx \
  --output real_data/converted-replay \
  --execution-probability 1
```

`1`明确表示“安排了就执行”的情景假设，适合先比较真实任务与耗时下的规划质量，**不验证用户执行概率建模效果**。不是已测得的真实概率，也不是模型预测结果。不能因哪个概率对本方法有利而选哪个。需要敏感性分析时，可预先确定对全部方法相同的0.75、0.9、1等情景，分别导出到新目录，分开报告。

有未完成或取消任务时，默认回放转换会报错，但观测模式可正常导出。只有明确接受选择偏差，才加 `--allow-completed-subset`，仅对已完成且耗时已知任务回放；不能称为完整真实任务流实验。任务可能截止在观察期外；现有WOTCR只统计观察期内到期任务，分析前检查分母。

输出：

- `observed_tasks.jsonl`：所有任务、实际完成时间、发布到完成分钟数、未完成删失标记和随访时间。取消单独保留，不当作普通右删失。
- `observed_sessions.jsonl`：实际执行与跳过记录，不作为反事实回放的未来输入。
- `scenario_instances.jsonl`：现有日程评估器可读的任务/固定安排/隔离真值。仅回放模式生成；真实完成时刻不作为规划器输入。
- `conversion_report.json`：源文件哈希、样本量、排除记录、执行概率假设和限制。

## 运行全部独立真实场景

```bash
python evaluation/run_evaluation.py \
  --dataset real_data/converted-replay \
  --config evaluation/config_integrated.json \
  --checkpoint checkpoints/chronoflow_best.pt \
  --split all \
  --methods edf priority_edf deterministic probabilistic global_probability personalized risk_aware drp_full \
  --seeds 11 \
  --output evaluation/results/real-replay-seed11
```

必须使用 `--split all`：真实外部测试集不再按哈希丢进训练/验证分区。所有输出目录必须是新目录；已有目录请换名称，转换器不覆盖原始数据。

这是**真实任务+实测耗时+假定执行行为的反事实仿真回放**，不是多个baseline均由用户真实执行的随机对照试验。规划器从冷启动开始；在线更新来自各自模拟反馈，不回灌真实未来结果。默认配置可工作时间08:00–22:00、每日最多360分钟、30分钟槽；应在测试前确认适用性，并为所有方法固定同一配置。分钟记录不会静默取整，现有执行仿真依然有30分钟分辨率。

当前bootstrap按观察场景聚类，同一用户多个观察期存在相关性，不能把这些窗口当成独立用户，也不能直接当作用户级显著性结论。表格需报告用户数、任务数、观察时长、取消与未完成数量、纳入回放数量及概率假设。不得在这个外部测试集上调参。
