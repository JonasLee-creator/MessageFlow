# Android 账号与 AI 接口

主工程为 `apps/android`。登录、注册、游客工作空间，以及官方 / 用户 AI 接口与网页版采用相同的产品流程。

## 登录和本机数据

- 首次进入显示登录页，使用用户名和密码；可以切换注册，填写确认密码。
- 右下角“游客模式”直接进入功能区，右上角提供“退出登录 / 返回登录”。
- 用户名为2–24个字，不区分大小写；注册密码为8–128位。使用随机盐与 PBKDF2-HMAC-SHA256 保存密码校验值，不保存明文密码。
- 账号记录、当前登录身份和工作空间均由 Android Keystore + AES-GCM 加密保存。密码输入不写入 Activity 保存状态。
- 游客继续读取原有 `local-state.enc`，不会将旧任务转移到新注册账号。每个账号单独使用 `workspace-<id>.enc`；账号名不会用于文件路径。
- 登录状态可在应用重启后恢复，以便继续本地提醒与通知采集。退出登录会保留计划、清除该工作空间的模型密钥和体验码，并停止其提醒与采集；重新进入工作空间后恢复对应计划。
- 后台 AI、Canvas 与提醒使用工作空间版本校验，旧请求的结果不能写入另一个账号。

这些是当前手机的本机账号，不是云账号。网页和 App 之间不共享注册信息、密码或任务，也不实现跨设备同步。

## 官方接口：比赛使用

开发者密钥只配置在网页版 Node.js 网关的运行环境中，不能写入 APK、Gradle 属性或资源文件。网关配置见 [网页版 API 配置](../apps/web/API.md)。

App 在“设置 → AI 接口”中选择“官方接口”，填写已部署的 HTTPS 官方服务根地址与体验码，保存后测试连接。App 的通知识别、今日摘要、风险预测与每周复盘都通过同一网关调用模型。

比赛构建属性：

```properties
chronoflowApiStage=competition
chronoflowGatewayUrl=https://chronoflow.example.com
```

以上 URL 是占位示例，需要替换为实际部署地址；也可在 App 设置中填写地址。构建属性不包含任何密钥，默认阶段为 `competition`。

网关新增原生协议接口：

| 方法 | 路径 | 作用 |
| --- | --- | --- |
| GET | `/api/v1/ai/config` | 获取服务状态和阶段 |
| POST | `/api/v1/ai/test` | 测试连接 |
| POST | `/api/v1/ai/mobile/analyze` | 返回 App 原有的 action、target_id、证据、问题、子任务等结构 |
| POST | `/api/v1/ai/mobile/report` | 返回今日摘要、风险预测或每周复盘 |

原生请求不发送浏览器 Origin；官方模式仍必须携带 `X-ChronoFlow-Access-Code`，并与网页共享限流、每日额度和正式环境禁用策略。通知最大5000字，发送上下文时限制数量与大小；模型提示词由服务端固定，客户端不能覆盖。

## 用户接口：正式使用

正式构建设置：

```properties
chronoflowApiStage=production
```

同时将网关环境改为 `CHRONOFLOW_STAGE=production` 并重新部署。App 正式构建禁用官方选项，网关也会拒绝官方模式请求。使用正式构建打开原有官方配置时，会关闭 AI、切换到用户接口并清除体验码，等待用户自行配置。

用户填写自己的 HTTPS Base URL、模型名称与 API Key。支持兼容 Chat Completions 的服务，可填写根地址、`/v1` 或完整 `/chat/completions` 路径。此模式从手机直接请求用户选择的服务商，不依赖开发者网关，也不会回退使用开发者密钥。

密钥和体验码不写入 UI 保存状态、URL 或日志；随对应工作空间加密保存在本机，退出登录时清除。与网页版的标签页会话存储不同，App 可以在进程重启后继续读取已保存的模型配置。连接测试会保存当前配置并发出实际模型请求，可能产生服务商费用。

## 识别与数据兼容

- 通知采集、Canvas、任务、固定日程、排程、执行记录与个人时间模型继续沿用现有流程。
- AI 结果始终进入“发现”核对；自动应用设置仅对明确的本地规则新事项生效。修改和取消仍须选择有效目标。
- AI 出错时明确提示并使用本地规则，不切换另一种 API 或服务商。
- 数据 schema 升为3，兼容读取1、2版本。旧 DeepSeek 密钥和模型作为用户接口配置读取；原字段名称保留用于兼容，不代表接口仅支持 DeepSeek。
- 未登录时不处理群通知，也不发送 AI 或 Canvas 请求。显式退出后会取消当前提醒；Canvas Token 保留在其加密工作空间中，不会被其他账号读取。

## 后续验收入口

源码提供 `ApiPolicyTest`、`AccountStorageTest` 与更新后的 `NavigationTest`，以及网关的离线原生协议检查。Android 仍需完成 Gradle 编译、设备登录/切换、Keystore 恢复、真实 API、后台采集与提醒验收。检查脚本与测试源代码不代表已经完成验收。
