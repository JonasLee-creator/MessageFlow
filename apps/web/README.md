# 时序 · 网页版初稿

浏览器本地交互原型，独立于 Android 主线和旧后端运行。当前使用 HTML / CSS / JavaScript，无第三方依赖或构建步骤。

## 本地预览

在 `apps/web` 目录执行：

```powershell
node server.mjs
```

打开 http://127.0.0.1:4173/ 。可通过 `PORT` 环境变量改变端口。服务器只监听本机。

## 当前功能

- 今天、发现、任务、日历、复盘、设置六页；适配桌面和窄屏。
- 演示通知核对，延期更新、新增任务与新增日程；修改需要确认。
- 手动粘贴通知，简单规则识别日期与耗时，结果均待确认。
- 创建和编辑任务、课程筛选、搜索、完成并记录实际耗时。
- 日 / 周日历、周切换、锁定时间块；桌面拖动后锁定，校验冲突与截止。
- 30 分钟粒度、未来 14 天的简单排程；保留锁定和已开始安排，显示缺口。
- 每日可用时间、JSON 导出、恢复演示数据。
- 使用 `localStorage` 保存当前浏览器内的数据，刷新后保留。

## 边界

尚未接入账号、手机同步、真实 Canvas、DeepSeek 或浏览器推送；界面中明确标注。页面内的微信 / QQ / Canvas 信息均为演示数据。数据未使用手机端的加密存储，初稿不适合保存敏感原文或凭据。

当前本地排程为简单启发式，与 Android 的个人学习模型和不确定性引擎尚未实现功能一致。日期以浏览器时区显示；相对日期以录入当日为基准。当前手动提取仅产生新增任务提议，修改、取消和多事项需要人工处理。

浏览器清除数据或切换站点会使用新的本地记录。JSON 导出供留存，尚未提供导入。后续正式前端可在保持界面结构的基础上迁移到 React，并通过统一 API 接入同步。

## 检查

```powershell
npm run check
```

包含 JavaScript 语法与排程不冲突、截止约束、锁定保留、工作量不重复、缺口和日期解析检查。检查不连接网络或真实服务。
