# 时序 · ChronoFlow Web

网页暂不接入本项目训练的日程模型。保留任务、日历、发现、复盘、基础排程和Canvas作业导入；模型主要入口位于Android，详见 [手机端模型](../../docs/ANDROID_EMBEDDED_MODEL.md)。

## 运行

Node.js 20.6+，在此目录运行 `node server.mjs`，打开 `http://127.0.0.1:4173/`。无需前端依赖安装或构建，也不需要启动Python模型服务。已移除规划模型的按钮、设置、客户端脚本和代理路由。

Canvas通过学校官方API及Access Token导入作业，先进入发现，由用户核对后加入日程。网页每次最多读取10门课程、每门3页、共300项；截断会提示。Token仅在本次请求使用，不存入浏览器，拒绝跨站分页及重定向，不收集学校密码。App保留更完整的课程、公告和日历同步。学校禁用个人Token时需要管理员OAuth支持。

可选LLM文本识别接口独立保留，参见 [API配置](API.md)；这是文本识别，不是本项目训练的日程规划模型。选择LLM识别会将通知正文及相关任务发送给所选服务。

任务、通知和计划保存在当前浏览器localStorage，按本机用户隔离，无跨设备云同步；请导出JSON备份。微信/QQ系统通知采集只在Android提供，默认关闭。

`npm run check` 验证语法、账号隔离、基础排程约束、LLM接口及Canvas来源/分页，并检查网页没有训练规划模型调用。模拟网站请求不等于真实学校站点联调。
